# DeepSeek Harness 桌面端

把 DeepSeek Harness 装进一个原生窗口的 PC 客户端:下载一个 exe,双击就能用,
不用再开浏览器标签页,也没有烦人的命令行黑框。

> 本项目位于本仓库的 **`dsh-desktop/`** 子目录下,下面都是普通用户的使用说明;
> 开发者/从源码运行请见子目录内的 [`dsh-desktop/README.md`](dsh-desktop/README.md)。

---

## 🎯 这是什么

- **给谁用**:电脑上已经在用 DeepSeek Harness(DSH)的人,想省去"开浏览器、切标签页"的麻烦。
- **能做什么**:用单独的原生窗口打开你本机的 DSH 界面(`http://127.0.0.1:3080`),
  DSH 服务没启动时会自动帮你启动;退出时自动判断关不关服务。
- **不做什么**:它**不含 DSH 服务本体**,只是一个"窗口外壳"——使用前你的电脑上需要已经能运行 DSH。

---

## 📥 下载与安装(普通用户)

1. 点本仓库右侧 **Releases**,下载最新的 `DeepSeek Harness 桌面端 x.x.x.exe`;
2. **放到一个专门的文件夹里**(如新建 `D:\dsh-desktop`,别放"下载"文件夹);
3. 还没装过 DSH 的话,先按下一节安装(只需一次);
4. **双击运行**。

> 🛡️ 第一次双击若弹"Windows 已保护你的电脑":点 **"更多信息" → "仍要运行"** 即可,以后不会再问。

### 🔧 安装 DSH(DeepSeek Harness)· 只需一次

DSH 是桌面端背后的服务本体,通过 npm 安装,整个过程不需要会编程:

1. **安装 Node.js**:打开 https://nodejs.org/zh-cn ,下载 **LTS** 版安装包,一路"下一步"装完;
2. **打开命令提示符**:按 `Win + R`,输入 `cmd`,回车;
3. **粘贴并运行下面的命令**,回车等待安装完成(出现 `@deepseek-ai/dsh` 字样即成功):
   ```cmd
   npm install -g @deepseek-ai/dsh
   ```
4. **验证(可选)**:输入 `dsh -V`,能打印出版本号就装好了。

装好后**直接双击桌面端 exe** 即可——它会自动用 `dsh web` 启动本地服务并进入界面。

> 💡 **如果应用还是提示"需要先安装 DeepSeek Harness"**:
> 说明系统 PATH 里找不到 `dsh` 命令(自定义过 npm 安装目录时常见)。在命令提示符输入
> `where dsh` 找到 `dsh.cmd` 的完整路径,然后给应用设置环境变量 `DSH_CMD` 指向它,
> 重新打开应用即可(详见子目录 [`dsh-desktop/README.md`](dsh-desktop/README.md))。

## 🚀 使用

1. 双击 exe → 窗口先显示"正在启动本地服务";
2. 应用自动检测并启动 DSH 服务(全程静默,无命令行窗口、不弹浏览器);
3. 服务就绪 → 自动进入 DSH 界面。

- **退出时智能关服务**:浏览器也在用 DSH 时保留服务,只有确认"仅桌面端在用"才关闭。
- 窗口顶部菜单:视图 → 后退/前进/刷新/回到首页、开发者工具 (F12)、缩放;外部链接交系统浏览器打开。
- 数据都在 exe 旁边的 **`userdata/`** 文件夹,备份/换机拷走即可。

## ❓ 常见问题 (FAQ)

**Q:打开后显示"需要先安装 DeepSeek Harness"?**
说明本机还没有 DSH:① 按上文「安装 DSH」的步骤装好;

② 或把 `dsh` 目录加入 PATH;③ 或设置环境变量 `DSH_CMD` 指向 `dsh.cmd` 完整路径。
做完后**完全退出并重新打开应用**。

**Q:一直停在"正在启动本地服务"?**
检查 3080 端口是否被占用,点"立即重试";还不行就查看 `userdata/` 下的 `main-error.log`。

**Q:双击没反应 / 转圈后无事发生?**
请确认下载的是**最新版** exe(早期版本有个启动 bug 已修复)。仍有问题请把
`userdata/` 下的 `main-error.log` 内容反馈给作者。

**Q:会泄露我的会话记录、API key 吗?**
**不会。** 应用不含任何密钥,会话数据只存在本机 DSH 数据目录和你的 `userdata/` 里,
不会上传到 GitHub 或任何地方。

**Q:怎么卸载?**
退出后删除 exe 和旁边的 `userdata/` 文件夹即可(免安装绿色软件)。

**Q:我已经装了 DSH,为什么还提示"需要先安装"?cmd 里 `dsh` 也用不了?**
这通常是 **dsh 装了,但它所在的目录不在系统 PATH 里**。判断方法:
在 PowerShell 里运行 `npx @deepseek-ai/dsh web` 能正常打开网页端 → 说明**确实装好了**,
只是 `dsh` 命令没进 PATH。所以 cmd 里 `dsh web`、`dsh -V` 会报"不是内部或外部命令",
这**不是没装**,而是 PATH 的问题。

**Q:为什么我每次用都要重新跑一遍安装命令?**
其实**不用每次重装**。如果每次是用 `npx @deepseek-ai/dsh web` 来启动,npx 每次都会重新解析包,
所以感觉像"又来一遍"。`npm install -g @deepseek-ai/dsh` 装一次就够了。

**Q:那怎么一次性修好,以后双击就能用?**
把 npm 全局目录加进系统 PATH(只需一次):
1. 运行 `npm config get prefix`,记下打印的目录(如 `C:\Users\你\AppData\Roaming\npm`);
2. `Win+R` → 输入 `sysdm.cpl` → 回车 → **高级** → **环境变量** → 在"你的用户变量"的
   `Path` 里**新建**一项,填入上面那个目录 → 确定;
3. **重启电脑**。
之后 `dsh -V`、`dsh web` 都能用,**双击桌面 exe 直接进界面**,不用再手动敲任何命令。
> 只想让桌面端能用、不想改系统设置?在 cmd 里运行 `setx DSH_CMD "…\dsh.cmd"`
> (路径 = `npm config get prefix` 的输出 + `\dsh.cmd`),然后重启——但那样 cmd 里敲
> `dsh` 依然不行。
